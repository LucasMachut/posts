Photos d'origine

Pour écrire les JPEG en pleine résolution, le navigateur doit lire tes fichiers lui-même. Les aperçus affichés à l'écran ne suffisent pas.

Choisis le dossier qui contient tes photos d'origine. C'est demandé une seule fois par session, ensuite l'export part tout seul.

Dans la fenêtre, sélectionne les images (Ctrl+A prend tout le dossier). Choisir un dossier entier fait passer le navigateur sur tous ses sous-dossiers, ce qui est très lent si un catalogue Lightroom traîne dedans.

Comment ça marche

Photos. Clic sur une photo pour ouvrir la banque et la remplacer. Glisser dessus la recadre, la molette zoome. Le bouton ⚙ ouvre rotation, recadrage précis et réglages du voile.

Texte. Clic dedans pour écrire. La pastille brune au-dessus du bloc le déplace n'importe où. A+ / A− règlent la taille de cette page, le curseur « taille » celle de tout le document.

Format. Le menu propose les formats courants, et les deux champs de pixels acceptent n'importe quelle dimension. Les pages et l'export suivent immédiatement.

Export JPEG. Le bouton exporter les planches JPEG fabrique chaque page en pleine résolution et télécharge un seul fichier .zip contenant toutes les planches (un zip évite que Chrome bloque les téléchargements multiples). Les photos chargées depuis le PC sont relues dans leur fichier d'origine, donc aucune perte et aucun passage par un PDF ou une capture d'écran. S'il manque une photo, le navigateur demande de désigner le dossier qui la contient.

Sauvegarder. Automatique dans le navigateur, mais utilise sauver maquette pour garder un fichier .json à toi.

Clique n'importe où pour fermer.
